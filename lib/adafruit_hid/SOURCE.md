# adafruit_hid について

出典: https://github.com/adafruit/Adafruit_CircuitPython_HID (MIT License)

このディレクトリには、本実験(`src/pico_ducky/code.py`)が使用する最小限のモジュールのみを
取得して配置しています(`mouse.py`や`keyboard_layout_win_ja.py`等の未使用モジュールは含めていません)。

- `__init__.py`
- `keyboard.py`
- `keycode.py`
- `keyboard_layout_base.py`
- `keyboard_layout_us.py`

ライセンス表記は各ファイル冒頭のSPDXヘッダーの通りです(MIT License, Copyright Scott Shawcroft
for Adafruit Industries他)。最新版が必要な場合は、上記リポジトリまたは
[CircuitPython Library Bundle](https://circuitpython.org/libraries)から取得し直してください。
